# Forms回答→Excel整理→Teams通知

社内の非機密アンケートの受付を、回答IDで重複排除しExcelテーブルへ追加、Teamsへ受付IDだけ通知する場面。

同梱：入力サンプル、期待出力、導入手順、AIプロンプト、受入試験、戻し方。
本商品は既製テンプレートです。M365への自動インポート・顧客環境設定代行は含みません。

[導入手順](SETUP.md) / [テスト](TEST.md) / [利用条件・限界](LIMITATIONS.md)

Python 3.10以上の標準ライブラリでサンプルを実行できます。納品版では同梱のautomation/patch_runner.pyを使用します。
